# Molplotter · 线刻分子实验

纯 JavaScript、无第三方依赖、无构建步骤。白底黑线，可叠加浓度与饱和度可调的元素填色，并整体偏移色层模拟套色印刷；不使用纸张纹理、噪声、褪色或灰度渐变。

## 使用

双击 `index.html`，选择单球、双球、水或乙醇；调整视角、三种模式共用的密度/大小/对比度、独立轮廓线宽、填色和光源角度，下载 SVG。默认使用平行光，可勾选「点光源」并调整距离；「渐变线宽（亮细暗粗）」默认开启。重置会恢复所有默认设置。页面不需要服务器或联网。直接查看样张可打开 `samples/*.svg`。

运行测试并重新生成样张：

```sh
node test.cjs
```

## 低锚点矢量路径

预览与 SVG 导出默认启用路径优化，无需额外操作。遮挡、受光和渐变线宽仍用原有高密度采样计算；只在生成路径时精简：

- 直的可见线段保留两个端点。
- 轮廓与等宽排线改用三次 Bézier 段，拟合容差 0.015 SVG 单位。
- 渐变排线对两侧边界分别拟合，容差取 `min(0.015, 该类线条基础宽度 × 0.025)`，不跨越尖端进行圆滑。
- 不合并不同的可见片段，因此遮挡断口、收尖、填色层和标签保留。

浏览器即使关闭填色，也须先加载新版 `wash.js`（共享曲线拟合器）。API 可传 `optimizePaths: false` 输出原始采样折线，用于诊断和比较；页面默认始终优化。优化针对导出路径数量与文件体积，不代表生成耗时一定更短。

`node test-optimize.cjs` 对单球、双球和乙醇的等宽/渐变六组进行路径一一对应、端点、尖端、闭合及双向边界误差验证。默认无填色乙醇的结果：

| 模式 | 锚点数（M/L/C 端点，不含控制柄） | SVG 字节数 |
| --- | --- | --- |
| 渐变排线 | 68,293 → 5,412（−92.1%） | 1,096,877 → 245,111（−77.7%） |
| 等宽排线 | 36,726 → 1,710（−95.3%） | 526,143 → 80,243（−84.7%） |

六组测试相对原始折线的最大采样双向边界偏差小于 0.023 SVG 单位；这是数值回归结果，不是对任意输入的全局误差证明。

## 元素上色

页面默认开启「元素上色」，浓度 65%、饱和度 100%，可以关闭恢复黑白图版。上色方式有两种，三种明暗模式均适用：

- **底色＋黑色纹理**（`colorMode: 'wash'`，默认）：保持原效果，碳暖灰、氢白、氧朱红、氮灰蓝、硫赭黄、磷橙，其他元素暂用暖灰；键保持白色。
- **彩色纹理＋白底**（`colorMode: 'ink'`）：不铺底色，直接给圆点、等宽排线或渐变排线边界着色。采用更深的墨色：碳赭棕（`#79451d`，避免细网点混白后退化成近灰色）、氧深红、氮深蓝、硫赭色、磷橙褐；氢、键及未知元素用中性灰，避免白色点在白底消失。轮廓仍为黑色，标签颜色仍由标签设置控制。

只改变颜色，不改变纹理几何、光照计算或遮挡位置。共用密度、大小、对比度保持不变。饱和度以 HSL 的 S 倍率计算并 clamp 到有效范围，不改变 L：0 为灰度、1 为原配色、4 为鲜明配色。浓度是与白色混合：0 为白色、1 为当前饱和度下的原配色，不是透明度叠加，因此遮挡处不会混色。颜色不随光照变化，明暗由所选排线、点刻或规则网点模式表达。

API 参数（为兼容之前调用，API 默认不开填色）：

```js
{
  colorWash: true,      // 元素上色总开关：API 默认 false；页面默认 true
  colorMode: 'ink',     // 'wash'（默认）或 'ink'
  washStrength: 0.65,   // 默认 0.65，范围 0–1；0 白色，1 原配色
  colorSaturation: 1,   // 默认 1，范围 0–4；UI 为 0–400%，步长 5%
  washOffsetX: 0,       // 默认 0，范围 −20–20，SVG 单位；正值向右
  washOffsetY: 0,       // 默认 0，范围 −20–20，SVG 单位；正值向下
  labelMatchFill: true  // API 默认 false；页面默认 true
}
```

X/Y 偏移按 0.5 SVG 单位调节，所有元素共用一次色层整体平移，而非逐元素移动。先按原始几何计算遮挡，再移动已经生成的色层，不重新裁剪：`wash` 移动底色，黑色纹理不动；`ink` 移动彩色纹理，黑色轮廓不动。标签始终不动，越出轮廓的印迹保留。关闭元素上色时禁用上色方式、浓度、饱和度和偏移控件但保留值；重置恢复 `wash` 与默认浓度等设置。

「描边自动匹配原子底色」按每个元素当前底色设置标签描边；关闭后可继续选自定义描边颜色。黑白模式和彩色纹理白底模式均自动匹配白色，不用墨色充当标签底色。描边宽度 0 始终关闭描边。

彩色纹理测试：`node test-color-ink.cjs`。样张：`samples/ethanol-ink-stipple.svg`、`samples/ethanol-ink-halftone.svg`、`samples/ethanol-ink-hatch.svg`（浓度 100%、密度 150%）。默认 65% 的墨色会更淡；需要更扎实的色调可将浓度提高到 100%。

浏览器需按 `wash.js` → `dots.js` → `renderer.js` → `app.js` 顺序加载（入口已配置），不需要安装包或联网。以下底色算法仅针对 `wash` 模式：填色用全部球体与键的前表面深度决定可见区域，不按球心前后叠圆。约 1 SVG 单位的网格只用于判断区域连接关系；边界位置再通过深度查询进行亚像素细化，并拟合成平滑三次 Bézier 路径，而不是把网格拐角直接导出。遮挡交界处的真实拐角与孔洞保留，输出不含位图或模糊滤镜。轮廓与排线仍在独立的上层，套印偏移作用于拟合后的色层。

这仍是数值近似，不是所有三维曲面交线的解析解；小于拓扑采样网格的极窄区域可能丢失，极大画幅会自适应加粗网格。圆形外边界和圆孔的径向误差由 `test-wash.cjs` 单独验证，阈值为 0.08 SVG 单位（包括测试用曲线离散化误差）；测试还检查整圈内外探针，避免只测锚点而漏掉曲线过冲。

运行填色遮挡与圆弧精度测试：`node test-wash.cjs`；连续边界和三色交界测试：`node test-wash-junction.cjs`。示例输出：`samples/ethanol-wash.svg`；无墨线检查可打开 `samples/fill-only.svg`。

## 调用渲染器

浏览器经典脚本 `renderer.js` 暴露 `MolEngraver`；Node.js 使用：

```js
const { render, examples } = require('./renderer.js');
const svg = render(examples.ethanol, {
  yaw: 0.25, pitch: -0.16, // 弧度
  shadingMode: 'hatch',  // hatch / stipple / halftone
  shadingDensity: 1,    // 0.4–2.5；UI 40–250%
  shadingSize: 1,       // 0–1.5；UI 0–150%，0 关闭明暗纹理
  shadingContrast: 1.2, // 0.5–2.5，三模式均生效
  outlineWidth: 0.8,     // 默认 0.8，UI 0–4；独立轮廓线宽
  variableWidth: true,   // 亮细暗粗，排线端部收尖；false 使用等宽 stroke
  lightAzimuth: -29 * Math.PI / 180,
  lightElevation: 32 * Math.PI / 180,
  lightType: 'directional', // 默认平行光；'point' 为点光源
  lightDistance: 3,      // 点光源距模型中心的距离，单位为场景包围半径 R
  crossHatch: true,
  labels: false,
  width: 900, height: 700
});
```

界面只保留一组 **密度、大小、对比度**，切换模式保留同一组数值，不再维护两套参数。`outlineWidth` 独立控制轮廓，不受大小与对比度影响。大小 0 关闭当前模式的排线或圆点，保留轮廓、底色及标签。

| 共用参数 | 排线 | 点刻 / 规则网点 |
| --- | --- | --- |
| `shadingDensity`（默认 1） | 排线密度 `round(24 × 倍率)` | 点间距 `5 / 倍率` SVG 单位 |
| `shadingSize`（默认 1） | 基础线宽 `0.8 × 倍率` | 点径倍率 |
| `shadingContrast`（默认 1.2） | 对明暗值作幂映射，影响可见排线及渐变线宽 | 点刻墨量或规则网点点径的明暗映射 |

对比度越高，浅调子更淡、深调子更突出；三种纹理的视觉效果不保证相同，但控制方向一致。排线等宽模式也会通过明暗阈值响应对比度。默认值保持原有样式。交叉排线和渐变线宽仍为排线专属选项。

兼容旧 API：`density`、`hatchWidth`、`dotSpacing`、`dotSize`、`dotContrast` 仍可用于已有脚本；只有显式传入相应共用参数时，才覆盖其旧参数。未指定线宽项时仍回退到旧 `lineWidth`，轮廓球体 1.4 / 键 1.1 倍率保持不变。页面仅使用共用参数和独立 `outlineWidth`。

验证：`node test-shared-controls.cjs`；界面切换、参数保留和重置由 `node test.cjs` 检查。

自定义模型格式：

```js
const molecule = {
  name: '示意模型',
  atoms: [
    { element: 'C', position: [-0.8, 0, 0] },
    { element: 'O', position: [0.8, 0, 0] }
  ],
  bonds: [[0, 1]] // 原子下标；目前仅支持单根圆柱键
};
```

## 元素标签样式

勾选「元素标签」后可调整字号、字体、粗体/斜体、文字颜色、描边宽度及颜色。字体输入框提供常见字体候选，也可直接输入本机字体名称或逗号分隔的回退列表。清空输入时使用默认字体。以下参数仅影响元素标签，不改变图版标题：

```js
{
  labels: true,
  labelSize: 17,           // 6–96，SVG viewBox 单位
  labelFont: "Georgia, 'Times New Roman', serif",
  labelBold: false,
  labelItalic: true,
  labelColor: '#161616',
  labelStrokeWidth: 4,     // 0–16，0 关闭描边
  labelStrokeColor: '#ffffff'
}
```

描边先画、文字后画，默认白色描边用于隔开排线；更换描边颜色可以形成彩色边缘。颜色参数使用六位十六进制。字号与描边宽度随整个 SVG 缩放，粗描边会向字形内外扩展、内侧部分由文字填充覆盖。标签隐藏时样式控件禁用但保留值，重置恢复默认。

字体不自动下载、不嵌入 SVG，也不转曲；未安装的字体会回退，换机器打开可能不同。大字号或粗描边可能遮住附近形体，目前不做标签碰撞避让。基线偏移随字号调整，不是基于每种字体的精确字形居中。

## 实现

- 正交相机位于 +Z 一侧，沿 −Z 看向模型（前方是较大的 Z）；可调相机空间光源，独立于分子旋转。API 参数 `lightAzimuth` 和 `lightElevation` 均为弧度，默认 −29°、32°。方位 0° 为正前方、90° 为右侧、−90° 为左侧、±180° 为背后；仰角正值向上。界面使用角度，重置会还原光源。
- `lightType` 默认为 `'directional'`（平行光），可设为 `'point'`（点光源）。点光源沿当前方位与仰角方向，位于距模型中心 `lightDistance × 场景包围半径` 的位置；`lightDistance` 默认 3，界面范围 1.2–12、步长 0.1，显示如 `3.0 R`。距离沿当前方向从模型中心移近移远，不是独立 Z 轴。平行光模式禁用距离滑块并显示 `∞`。核心逐点计算表面位置到点光源的方向，仅模拟方向变化，不模拟距离亮度衰减；两种光源均无投射阴影。
- `variableWidth` 默认为 `true`：排线以封闭实心 SVG 路径输出，亮部细、暗部粗，端部收尖；轮廓维持可读性，不收尖。关闭界面开关或传入 `false` 后回到等宽 `stroke`，仍由 `hatchWidth` 控制排线基础线宽（兼容旧 `lineWidth` 回退）。
- 球面与倾斜平面相交生成真实三维小圆，投影成弧线；根据表面法线与光照的点积截取亮暗区域。暗部可叠加第二组排线。
- 键是有限长圆柱，包含端盖深度测试；轮廓和轴向细线表达形体。
- 对每条曲线逐点做射线与全部球体/圆柱的解析深度比较，仅输出可见段，不依赖原子中心深度排序。
- 固定采样、确定性输出；输出是 SVG 路径、圆点和文字，不是位图滤镜。

## 点刻与规则网点

「明暗模式」默认 `hatch`（排线），也可选择 `stipple`（点刻）或 `halftone`（规则网点）。三种模式使用上文同一组 `shadingDensity`、`shadingSize`、`shadingContrast`。以下旧网点参数仅供既有脚本兼容，界面不再单独提供：

```js
{
  shadingMode: 'stipple', // string：'hatch'（默认）| 'stipple' | 'halftone'
  dotSpacing: 5,         // 旧 API：2–14，SVG 单位
  dotSize: 1,            // 旧 API：0–1.5
  dotContrast: 1.2       // 旧 API：0.5–2.5
}
```

- **点刻**采用确定性的、带最小中心距离约束的抖动采样，不宣称严格蓝噪声。明暗不再只靠随机丢点：以受光和克制的掠射角调子估算目标墨面积，同时调整点数与点径，保留高光、建立中间调和核心暗部。暗部圆点允许相接或重叠，避免出现只有灰尘般细点、没有体积的效果。轮缘项是插图式调子，不是环境遮蔽或投射阴影。相同模型、视角与参数重复渲染得到相同结果。
- **规则网点**采用固定 45° 的相机平面点阵，网格不随模型表面旋转；以变化的圆点直径表达明暗，而不是改变点阵角度。
- 间距越小颗粒越细。`dotSize` 是相对点间距的尺寸倍率，两模式使用不同的基准直径；规则网点保留点间间隙，点刻暗部允许点相接。尺寸过小会降低整体墨量，建议先用 100%、对比度 1.2，再调间距获得细腻程度；尺寸 0 关闭圆点。圆点尺寸不受 `hatchWidth` 或旧 `lineWidth` 控制。
- 更换平行光或点光源的方向、位置会改变点刻疏密或规则网点点径；`dotContrast` 调节明暗映射。表面位置、法线和可见性取当前射线上最前面的 primitive（球体或有限圆柱及其端盖），而非按原子中心排序。无投射阴影与距离亮度衰减。
- 边缘圆点通过 16 个方向、两圈 footprint 测试和二分半径缩小避免溢出，并额外保留方向间隙与坐标舍入的安全边距；这是数值近似，不是精确 clip。导出直接使用 SVG `<circle>`，而不是逐点生成含多个锚点的路径。
- 轮廓始终独立，由 `outlineWidth` 控制；填色、套印偏移、光源和标签保持可用。三种模式始终启用同一组密度、大小、对比度；切换模式不会重置这三个值。仅交叉排线和渐变线宽在网点模式禁用并保留其值。所有控件沿用同一个 requestAnimationFrame 渲染调度。
- 重置恢复 `hatch`、密度 100%、大小 100%（API 均为 1）、对比度 1.2。浏览器需在 `wash.js` 之后、`renderer.js` 之前加载 `dots.js`，入口已配置。

运行 `node test-dots.cjs` 验证两种模式的确定性、规则点阵、疏密/点径变化、光源、独立圆点边缘遮挡及端视圆柱。测试用 64 个错相方向复查圆点边缘，而非仅重复渲染器的 16 个方向。

运行 `node test-stipple-tone.cjs` 检查无轮廓、无填色单球的实际圆点并集覆盖率：高光、中间调、暗部依次加深，改变光源方向会改变暗部方向，正面光下中央亮而四向球缘暗。默认测试样例覆盖率约为 1.6% / 15.8% / 42.6%，不是仅比较点数，也不把重叠面积重复计数。无轮廓细颗粒样张：`samples/sphere-volume-fine.svg`。

样张：`samples/sphere-stipple.svg`、`samples/sphere-halftone.svg`、`samples/ethanol-stipple.svg`、`samples/ethanol-halftone.svg`。若希望点刻更细密，可将共享密度从 100% 提高到约 165%（点间距约从 5 降到 3）；点数及文件体积也随之增加。

## 当前边界

这是视觉与几何原型，不是化学建模软件，也不声称准确复刻某一历史版画流派。示例坐标为手工示意，未经能量优化；显示半径用于球棍表达，不是范德华半径。没有 SMILES/XYZ 解析、多重键或立体化学输入。

可见性裁剪采用亚像素级附近的离散采样，不是精确曲线求交；放大后仍可能发现细小断口。排线模式下端盖仅参与遮挡；网点模式也会在可见端盖上生成圆点。默认键端埋在原子中。标签只是可选辅助，拥挤场景没有自动避让。复杂大分子的计算量随几何体和线样本数增长，目前面向小分子。

线宽与排线密度尚未按最终印刷毫米数标定，缩放输出后需检查可读性。中文标题依赖本机字体，SVG 未将文字转曲。

下一步应先与目标历史插图对照，调整排线方向、亮部留白和暗部层次，再考虑接入 RDKit.js 或真实坐标文件。
