# Molplotter · 线刻分子实验

纯 JavaScript、无第三方依赖、无构建步骤。白底黑线，可叠加浓度与饱和度可调的元素填色，并整体偏移色层模拟套色印刷；不使用纸张纹理、噪声、褪色或灰度渐变。

## 使用

双击 `index.html`，选择单球、双球、水或乙醇；调整视角、排线密度、独立的轮廓/排线线宽、填色和光源角度，下载 SVG。默认使用平行光，可勾选「点光源」并调整距离；「渐变线宽（亮细暗粗）」默认开启。重置会恢复所有默认设置。页面不需要服务器或联网。直接查看样张可打开 `samples/*.svg`。

运行测试并重新生成样张：

```sh
node test.cjs
```

## 低锚点矢量路径

预览与 SVG 导出默认启用路径优化，无需额外操作。遮挡、受光和渐变线宽仍用原有高密度采样计算；只在生成路径时精简：

- 直的可见线段保留两个端点。
- 轮廓与等宽排线改用三次 Bézier 段，拟合容差 0.015 SVG 单位。
- 渐变排线对两侧边界分别拟合，容差取 `min(0.015, 该类线条基础宽度 × 0.025)`，不跨越尖端进行圆滑。
- 不合并不同的可见片段，因此遮挡断口、收尖、填色层和标签保留。

浏览器即使关闭填色，也须先加载新版 `wash.js`（共享曲线拟合器）。API 可传 `optimizePaths: false` 输出原始采样折线，用于诊断和比较；页面默认始终优化。优化针对导出路径数量与文件体积，不代表生成耗时一定更短。

`node test-optimize.cjs` 对单球、双球和乙醇的等宽/渐变六组进行路径一一对应、端点、尖端、闭合及双向边界误差验证。默认无填色乙醇的结果：

| 模式 | 锚点数（M/L/C 端点，不含控制柄） | SVG 字节数 |
| --- | --- | --- |
| 渐变排线 | 68,293 → 5,412（−92.1%） | 1,096,877 → 245,111（−77.7%） |
| 等宽排线 | 36,726 → 1,710（−95.3%） | 526,143 → 80,243（−84.7%） |

六组测试相对原始折线的最大采样双向边界偏差小于 0.023 SVG 单位；这是数值回归结果，不是对任意输入的全局误差证明。

## 元素填色

页面默认开启「元素填色」，填色浓度 65%、饱和度 100%，可以关闭恢复黑白图版。碳暖灰、氢白、氧朱红、氮灰蓝、硫赭黄、磷橙，其他元素暂用暖灰；键保持白色。饱和度以 HSL 的 S 倍率计算并 clamp 到有效范围，不改变 L：0 为灰度、1 为原配色、4 为鲜明配色。浓度是与白色混合：0 为白色、1 为当前饱和度下的原配色，不是透明度叠加，因此遮挡处不会混色。颜色不随光照变化，明暗仍由排线表达。

API 参数（为兼容之前调用，API 默认不开填色）：

```js
{
  colorWash: true,      // API 默认 false；页面默认 true
  washStrength: 0.65,   // 默认 0.65，范围 0–1；0 白色，1 原配色
  colorSaturation: 1,   // 默认 1，范围 0–4；UI 为 0–400%，步长 5%
  washOffsetX: 0,       // 默认 0，范围 −20–20，SVG 单位；正值向右
  washOffsetY: 0,       // 默认 0，范围 −20–20，SVG 单位；正值向下
  labelMatchFill: true  // API 默认 false；页面默认 true
}
```

X/Y 偏移按 0.5 SVG 单位调节，所有元素共用一次色层整体平移，而非逐元素移动。先按原始几何计算遮挡，再移动已生成的色层；超出轮廓的色块仍保留，不重新裁剪。墨线、标签和遮挡计算不跟随平移，形成套色印刷的错位效果。关闭填色时禁用浓度、饱和度和偏移控件但保留值；重置恢复上述默认值。

「描边自动匹配原子底色」按每个元素当前底色设置标签描边；关闭后可继续选自定义描边颜色。黑白模式自动匹配白色。描边宽度 0 始终关闭描边。

浏览器需按 `wash.js` → `renderer.js` → `app.js` 顺序加载（入口已配置），不需要安装包或联网。填色用全部球体与键的前表面深度决定可见区域，不按球心前后叠圆。约 1 SVG 单位的网格只用于判断区域连接关系；边界位置再通过深度查询进行亚像素细化，并拟合成平滑三次 Bézier 路径，而不是把网格拐角直接导出。遮挡交界处的真实拐角与孔洞保留，输出不含位图或模糊滤镜。轮廓与排线仍在独立的上层，套印偏移作用于拟合后的色层。

这仍是数值近似，不是所有三维曲面交线的解析解；小于拓扑采样网格的极窄区域可能丢失，极大画幅会自适应加粗网格。圆形外边界和圆孔的径向误差由 `test-wash.cjs` 单独验证，阈值为 0.08 SVG 单位（包括测试用曲线离散化误差）；测试还检查整圈内外探针，避免只测锚点而漏掉曲线过冲。

运行填色遮挡与圆弧精度测试：`node test-wash.cjs`；连续边界和三色交界测试：`node test-wash-junction.cjs`。示例输出：`samples/ethanol-wash.svg`；无墨线检查可打开 `samples/fill-only.svg`。

## 调用渲染器

浏览器经典脚本 `renderer.js` 暴露 `MolEngraver`；Node.js 使用：

```js
const { render, examples } = require('./renderer.js');
const svg = render(examples.ethanol, {
  yaw: 0.25, pitch: -0.16, // 弧度
  density: 24,
  outlineWidth: 0.8,     // 默认 0.8，范围 0–4；0 关闭轮廓
  hatchWidth: 0.8,       // 默认 0.8，范围 0–4；0 关闭排线
  variableWidth: true,   // 亮细暗粗，排线端部收尖；false 使用等宽 stroke
  lightAzimuth: -29 * Math.PI / 180,
  lightElevation: 32 * Math.PI / 180,
  lightType: 'directional', // 默认平行光；'point' 为点光源
  lightDistance: 3,      // 点光源距模型中心的距离，单位为场景包围半径 R
  crossHatch: true,
  labels: false,
  width: 900, height: 700
});
```

`outlineWidth` 与 `hatchWidth` 独立控制基础线宽，单位为 SVG viewBox 单位，随整体缩放；页面均为 0–4、步长 0.05、默认 0.8。轮廓原有球体 1.4 / 键 1.1 倍率和原排线倍率保持不变。两项都设为 0 时不画分子墨线，仍可显示填色和标签。兼容旧 API：未指定的新线宽项回退到旧 `lineWidth`；若两项均未指定，`lineWidth` 同时控制两者；显式指定的新项（包括 0）优先，全部省略时均为 0.8。页面只传 `outlineWidth`、`hatchWidth`，不再传旧 `lineWidth`。

自定义模型格式：

```js
const molecule = {
  name: '示意模型',
  atoms: [
    { element: 'C', position: [-0.8, 0, 0] },
    { element: 'O', position: [0.8, 0, 0] }
  ],
  bonds: [[0, 1]] // 原子下标；目前仅支持单根圆柱键
};
```

## 元素标签样式

勾选「元素标签」后可调整字号、字体、粗体/斜体、文字颜色、描边宽度及颜色。字体输入框提供常见字体候选，也可直接输入本机字体名称或逗号分隔的回退列表。清空输入时使用默认字体。以下参数仅影响元素标签，不改变图版标题：

```js
{
  labels: true,
  labelSize: 17,           // 6–96，SVG viewBox 单位
  labelFont: "Georgia, 'Times New Roman', serif",
  labelBold: false,
  labelItalic: true,
  labelColor: '#161616',
  labelStrokeWidth: 4,     // 0–16，0 关闭描边
  labelStrokeColor: '#ffffff'
}
```

描边先画、文字后画，默认白色描边用于隔开排线；更换描边颜色可以形成彩色边缘。颜色参数使用六位十六进制。字号与描边宽度随整个 SVG 缩放，粗描边会向字形内外扩展、内侧部分由文字填充覆盖。标签隐藏时样式控件禁用但保留值，重置恢复默认。

字体不自动下载、不嵌入 SVG，也不转曲；未安装的字体会回退，换机器打开可能不同。大字号或粗描边可能遮住附近形体，目前不做标签碰撞避让。基线偏移随字号调整，不是基于每种字体的精确字形居中。

## 实现

- 正交相机位于 +Z 一侧，沿 −Z 看向模型（前方是较大的 Z）；可调相机空间光源，独立于分子旋转。API 参数 `lightAzimuth` 和 `lightElevation` 均为弧度，默认 −29°、32°。方位 0° 为正前方、90° 为右侧、−90° 为左侧、±180° 为背后；仰角正值向上。界面使用角度，重置会还原光源。
- `lightType` 默认为 `'directional'`（平行光），可设为 `'point'`（点光源）。点光源沿当前方位与仰角方向，位于距模型中心 `lightDistance × 场景包围半径` 的位置；`lightDistance` 默认 3，界面范围 1.2–12、步长 0.1，显示如 `3.0 R`。距离沿当前方向从模型中心移近移远，不是独立 Z 轴。平行光模式禁用距离滑块并显示 `∞`。核心逐点计算表面位置到点光源的方向，仅模拟方向变化，不模拟距离亮度衰减；两种光源均无投射阴影。
- `variableWidth` 默认为 `true`：排线以封闭实心 SVG 路径输出，亮部细、暗部粗，端部收尖；轮廓维持可读性，不收尖。关闭界面开关或传入 `false` 后回到等宽 `stroke`，仍由 `hatchWidth` 控制排线基础线宽（兼容旧 `lineWidth` 回退）。
- 球面与倾斜平面相交生成真实三维小圆，投影成弧线；根据表面法线与光照的点积截取亮暗区域。暗部可叠加第二组排线。
- 键是有限长圆柱，包含端盖深度测试；轮廓和轴向细线表达形体。
- 对每条曲线逐点做射线与全部球体/圆柱的解析深度比较，仅输出可见段，不依赖原子中心深度排序。
- 固定采样、确定性输出；输出是 SVG 路径和文字，不是位图滤镜。

## 当前边界

这是视觉与几何原型，不是化学建模软件，也不声称准确复刻某一历史版画流派。示例坐标为手工示意，未经能量优化；显示半径用于球棍表达，不是范德华半径。没有 SMILES/XYZ 解析、多重键或立体化学输入。

可见性裁剪采用亚像素级附近的离散采样，不是精确曲线求交；放大后仍可能发现细小断口。端盖仅参与遮挡，默认键端埋在原子中。标签只是可选辅助，拥挤场景没有自动避让。复杂大分子的计算量随几何体和线样本数增长，目前面向小分子。

线宽与排线密度尚未按最终印刷毫米数标定，缩放输出后需检查可读性。中文标题依赖本机字体，SVG 未将文字转曲。

下一步应先与目标历史插图对照，调整排线方向、亮部留白和暗部层次，再考虑接入 RDKit.js 或真实坐标文件。
