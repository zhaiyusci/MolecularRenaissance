# 元素纹理评审：连续网纹候选

**接入状态：评审后的纹样已进入应用。** 当前19元素正式映射见 [ELEMENT-TEXTURES.md](../../ELEMENT-TEXTURES.md)；新增网纹分配为B横长方网、Li竖长方网、Si正方网、Se扁菱形网、K三角网、Ca竖砖、Al横砖。C现再次采用斜交叉网 `crosshatch`：1倍时节距9 px、旋转45°、线宽0.55 px，与其他纹理笔画一致，不使用实心黑；只在开启 `elementTextures` 时作为分类纹理生效，不改色表或底色，关闭元素纹理保留原有配色与光影。所有网纹（含C）保持每小格81 px²（1倍）。当前元素纹理线宽为0.55屏幕px（1倍，含旧回退纹样），其余间距、网格几何、圆点、轮廓与光影参数不变。C与其他元素一样，分类纹理在光影和标签之前正常绘制，不再有C专用的光影后覆盖层；光影与标签设置不变。下文网纹评审及v1–v3均为历史设计记录，包括C粗线网、“尚未接入”“K待定”等说法，不代表当前应用映射。

### 本轮纠正：按小格大小对齐，不再硬凑19%墨量

上轮把覆盖率误当成纹样疏密，已撤销该约束。这一版把**每一个小格的几何面积设为81 px²**，即正方网9×9的量级；不是把SVG平铺矩形一律设成同样尺寸（三角网一个平铺矩形含4个小三角，砖纹含2块砖）。直径64 px的圆约容纳39.7个小格等效面积，边缘裁切的实际完整格数会有差别。

## 旧版 v3：核心六种 + F / Cl / Br

**这是设计样张，应用映射尚未修改。** 自定义方案，不是行业标准；不宣称 19 种在任意尺寸/遮挡下都可脱离标签识别。

## 本轮调整

- F、Cl、Br 纳入九种重点元素，分别采用**横波线、竖波线、斜波线**。三种使用完全相同的波形、节距和线宽，只改变整体方向，不靠波峰形状的细微变化区分。
- 全部删除虚线，避免缩小时与 S 的点纹混淆。
- 删除用波线/锯齿折线作区别的方案。
- 保留双线和砖纹，增加较大节距的**连续回纹**候选。回纹不是重复的小“回”字图标，而是跨单元接续的回折线结构；复杂内部仍可能在缩版或遮挡时丢失，尚未定稿。

## 仍需观察

- 卤素的波形片段在窄遮挡区域中可能接近直线；优先级提高不等于可辨识性已经验证。
- 成对线要看双线间隙能否保留、是否被遮挡成单线。
- 砖纹需露出横纵连接；回纹需要更大的可见面积。不能为补足元素数量而无限缩小图案。
- S 实心点在整体缩版时仍会变小。小尺寸/严重遮挡保留标签与图例，不能自动更换纹理破坏固定映射。
